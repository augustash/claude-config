# AshenRayne sites

claude-config serves both studios, and almost all of it is shared: the skills, the rule sets,
the patterns. This topic holds only what splits, so the two never have to be untangled later
(Kaza, 2026-10-24). When something new splits by studio (a list, a tracker, a convention), it
goes here, not into an August Ash file with an exception clause.

| Code | Project | Site | Host |
|---|---|---|---|
| LOCAL49 | `local49` | local49.org (WordPress) | SiteGround |
| MD | `md` | dmx-power.com (Drupal) | Pantheon `ar-md` |
| OF | `of` | Olympic Foundry (Drupal) | Pantheon `ar-of` |
| SU | `su` | syracuseutilities.com (WordPress) | Pantheon |
| TELOS | `telos` | Telos (Drupal) | Pantheon `ar-telos` |

The code is the project's short name, upper-cased. Tests on these sites are tagged `ar` (see
[[test-tags]]). When a site joins, add a row here and a key to the tracker below.

## What differs on an AshenRayne site

- **No plans.** POM is an August Ash offering. Every round covers everything: the updates plus
  every pass pom-plus describes, and the client gets one report, billed monthly. Never name POM,
  POM+ or a plan in the record, or offer an upgrade (Kaza, 2026-10-19).
- **Prices stand alone.** A Work row states the price (*$400*), never hours × rate.
- **The record carries the passes in the Health bar**, not a POM+ bar: see client-report,
  *AshenRayne records*.
- **The studio mark is the Ashen Rayne shield**, not the August Ash A
  ([doc-studio-mark](../preferences/doc-studio-mark.md)).

[accessibility.json](accessibility.json) lists the quarters done per site, in the same shape as
